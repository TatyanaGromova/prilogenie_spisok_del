# Делай любя, люби себя

Эстетичный дневник чувств и дел в одном HTML-файле с сохранением данных в `localStorage`.

## Что внутри

- Дневник чувств и мыслей
- Выбор настроения (line-art иконки)
- Дела дня (включая автодела от привычек)
- Благодарность и маленькая победа дня
- История записей
- Светлая/тёмная тема с переключателем
- Нижняя мобильная навигация
- Трекер привычек и расписания

## Стек

- `HTML + CSS + JavaScript` (без внешних JS-библиотек)
- Google Fonts: `Cormorant Garamond`, `Manrope`
- Хранение данных: `localStorage`

## Быстрый старт

1. Склонируй репозиторий.
2. Открой файл `loving_diary_app_improved.html` в браузере.
3. Пользуйся приложением без установки зависимостей.

## Хранилище данных в браузере

- Основные записи: `lovingDiaryApp_v3`
- Легаси-ключ: `lovingDiaryApp_v2`
- Тема: `lovingDiaryTheme`
- Привычки: `lovingDiaryHabits_v1`
