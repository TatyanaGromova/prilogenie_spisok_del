# Support

## Getting Help

If you need help with setup or behavior:

1. Read `README.md`
2. Check open and closed issues
3. Open a new issue using the appropriate template

## Before Opening an Issue

- Confirm the bug is reproducible
- Include browser and OS details
- Include exact steps and expected result

## What This Project Supports

- Modern Chromium-based browsers
- Firefox (recent versions)
- Mobile browser usage with bottom navigation
