# Security Policy

## Supported Versions

Security updates are currently provided for the latest state of the `main` branch.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue first.

Please report it privately with:

- A clear description of the vulnerability
- Reproduction steps
- Potential impact
- Suggested mitigation (if available)

Maintainers will acknowledge the report and provide a remediation timeline.

## Scope

This policy applies to:

- Source code in this repository
- Application behavior related to data persistence and client-side logic
